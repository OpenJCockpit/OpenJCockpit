# @openjcockpit/api

Contract layer of the dashboard: every HTTP client, DTO type and pure DTO selector.

- **Exports:** `API_BASE_URL`, `setAuthToken()`, `authHeaders()`, `errorMessageFrom()`; `apiRequest()`, `apiRequestVoid()`, `ApiError`, `isAbortError()`, `setSessionRefresher()`; the DTO types; the project, spec, skills-marketplace, workspace, workflow and spec-queue clients; `workflowsForProject()`, `candidateOrbTargets()`, `runStatus*()`/`buildAgentCards()`/`buildSequencerNodes()`, `referenceLabel()`. Mock workspace and workflow fixtures are test-only and live in `@openjcockpit/api/testing` (`src/testing`); they are not a production fallback.
- **Layout:** `core/` (base URL, token, error parsing), `types/`, `projects/`, `specs/`, `skills-marketplace/`, `workspace/`, `workflow/`, `spec-queue/`; everything is re-exported from `src/index.ts`.
- **Rules:** pure code only. No React, no components, no `localStorage`. Every client goes through `apiRequest`/`apiRequestVoid` (ESLint bans a raw `fetch` in this lib outside `core/http.ts`), which send the bearer token, accept an abort signal and, on a 401, call the registered session refresher and retry once.
- **Auth token:** `setAuthToken` holds module state, so exactly one copy of this library must exist in the bundle. The app's auth effect is the only writer.
- **Tag:** `type:data`. May depend only on `type:util` libraries (enforced by `@nx/enforce-module-boundaries`), so it must not import `@openjcockpit/ui`.
- **Tests / checks:** `nx run api:test`, `api:lint`, `api:typecheck`, `api:format-check`.
- **Generated types:** `src/generated/contract.ts` is generated by Orval from `shared/contracts/openapi.yaml` (types only; the clients are hand-written). `types/`, `workflow/workflowTypes.ts` and `spec-queue/specQueueTypes.ts` re-export it under the names the app uses and add only UI-only types. Change a type by editing the contract, then run `nx run api:generate` and commit the result. CI fails if the output is stale. Mark always-present fields `required` in the contract, otherwise they come out optional.
